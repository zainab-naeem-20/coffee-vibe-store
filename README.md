# ☕ Coffee Vibe Store

**An elegant, modern, and fully responsive web application designed for a coffee shop experience.**  
*Built with clean HTML5, CSS3, custom animations, and interactive elements.*

---

## ✨ Features

🎨 **Cozy Espresso Aesthetic**  
*Designed with a balanced warm mocha & caramel theme for a premium visual feel.*

📱 **Fully Responsive Layout**  
*Seamless UI experience across all mobile, tablet, and desktop viewports.*

🎭 **Smooth Scroll & Animations**  
*Integrated with AOS (Animate On Scroll) library for smooth transitions.*

☕ **Featured Menu Showcase**  
*Highlights popular coffee blends with hover-card details.*

💬 **Customer Reviews Section**  
*Interactive feedback and testimonial cards.*

📬 **Contact Form**  
*Sleek inquiry layout for user messages and reservations.*
